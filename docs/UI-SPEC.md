## 1. 不变量（不可协商）

判据是**破坏它会造成什么**,不是它写得多确定。前五条坏了会让人读出错误的结论或让某类用户用不了;
第六条是一条物理事实(对比度);视觉方向的其余部分都不在这里。

1. **不知道就是不知道。** 用量未知 ≠ 0、价格未知 ≠ 免费——界面必须把「未知」说出来,不静默按 0
   展示,也不把折算出来的数说成支出。这是数据层的承诺在界面上的那一半(`usageUnknown`、
   价格未知的判定都在 host 侧,界面不许把它抹平)。
2. **一处失败不许静默。** CSS 自定义属性必须在**声明处可解析**,否则整条声明在计算值阶段无声失效;
   跨节 / 跨 tab 复用的度量挂在插件根上,不挂在使用者那一节。
3. **颜色不许自造。** 底色、文本色、状态色一律走宿主 `--dsw-alias-*`,硬编码色值只许出现在
   `var(--宿主变量, #兜底)` 的兜底里;新增文本色必须在浅 / 深两套皮肤下各量一次,把实测值写进
   `styles/*.ts` 的注释。**不引入第二个色相**:需要分类时用形状,金额区分靠字重 + 桶名。
4. **焦点与键盘不参与这套视觉语言。** 焦点必须可见且不被遮挡、不跟风格走(跟随宿主);
   每个动作都要能不用指针完成;只给 pointer 的交互(拖拽 / 悬停)必须有键盘替代。
5. **无障碍底线是硬的。** 对比度 4.5:1 / 3:1 / 3:1(见 §2);颜色不单独承载语义(状态同时要有文字
   或形状);信息不能只存在于 `title`;`prefers-reduced-motion` 下动画全关且**关掉之后仍有反馈**;
   功能性图标一律内联 SVG,不用 emoji。
6. **黄是「料」,不是「线」。** 恒定黄只以**实心块 + 墨边**的形态出现(唯一例外是文本选区洗色);
   做 1px 线、做浅底文字、做大面积填充一律禁止——`#FFCD00` 压白卡只有 1.57:1,做线做字都会消失。

**不在不变量里的**:直角、金属边、面板配方、徽记、"黄出现在哪几处"、字号分带——那是下面这份
**当前语言**,大调整协议随时可以推翻它,只要登记。

## 2. 达标线（可判定）

**当前语言(可被大调整协议推翻,登记即可)。** 「明日方舟:终末地」的工业面板:黑白灰为基色、
金属只作点缀(一道 1px 机加工边:受光边 + 投影,≤12%)、直角硬边、品牌黄作锚点。三角写法:
**黄 = 料不是线**、**分类靠形状 / 金额靠字重 + 桶名**、**色相 = 「这里看一眼」**。第一条原理:
这是一个**密集数字**界面,加一层色相是在成本最高的地方加噪声。

**色相的三个来源。** 主题色(宿主 `--dsw-alias-*` 经 L2 别名成 `--dtpl-*`)、中性墨色
(`color-mix(fg N%, transparent)`)、状态色(`ok` / `warn` / `err`,**只在真的要看一眼时**)。
黄当前出现在这六类,都是实心块 + 墨边:窗口 tab 的当前页标记、峰值柱数值前的黄牌、节标题 /
口径词前的工业徽记、价格表「未保存」草稿点(窗口 tab 上那一枚同源)、文本选区。趋势柱、时间轴、
占比尺一律墨色。**预算是面积不只是处数**:黄一度几乎整块落在峰值柱上(≈全 UI 黄面积的 97%),
满屏唯一的饱和色落在最大的那块面上,读的是「报警」而不是分布的形状,于是撤到数值旁那枚小牌;
柱身试过的三版黄(角块 / 通宽柱脚 / 上下两条线)全部否掉。新增一处黄之前先问一句:
**它会不会成为全屏最大的一块饱和面?**

**`--dtpl-accent` 不是自由强调色。** 它在 DSH 默认皮肤里等于墨色
(`--dsw-alias-brand-primary` → `--dsw-static-neutral-bluish-1000` = `#0f1115`),所以拿它做
分类或状态是空操作;宿主同一条 CSS 里已经并排躺着一个 `--dsw-alias-brand-primary-new-color:
#4176e6`,这个值**会随皮肤变**。当前只许用在:焦点环(全局 `:focus-visible`)、输入框聚焦边框、
调价史轴上「当前生效」那枚点(它另有文字同义,不靠颜色单独说事)。

**对比度:文本 4.5:1、非文本(边框 / 条 / 图形)3:1、焦点指示 3:1。** 三条硬规则:

- **`fg-3` 只承载装饰**(插入符、窄屏页内小标签、轨道之外的点缀);**任何要读的文本都走 `fg-2`**
  ——包括**未被选中的选项**(「当前项」由字重 + 实条 + 洗色说,不靠把没选中的洗淡),也包括
  10px 的柱值、轴刻度、份额与环心单位。9px 能装下的字更少,不是可以更淡的理由。
- `warn` 不许直接做正文(浅色皮肤下只有 2.15:1),文字用 `warn-ink`;`warn` 本身留给边框与底色。
  `warn-ink` 是**派生色**,改它就要重走一次"两套皮肤各量一次"。
- **新增文本色必须先在浅 / 深两套皮肤下各量一次**,把实测值写进 `styles/*.ts` 的注释,再进 tokens。

**字号分带。** 9–10px 只给短标签(列头、柱值、芯片、徽章、轴刻度、表盘说明),它装不下一句话;
11–11.5px 是「说明句」的下限;**12px 起才是正文句**。判据是**这句话要不要读**,不是它有多重要。

**每个数只有一个归属地。** 常驻文案按它干的活分三类:**决策数据**(选哪条通道、哪段价生效——始终在场)、
**会变的状态**(未保存草稿、窗口剩余——只在一处说,别每个 tab 重说一遍)、**解释**(为什么、意味着什么——
可以收进一个显式且键盘可达的展开,但展开控件本身要能不用指针打开)。判据是**撤掉这一句之后还有没有
一个地方说得清它**;说得清就是重复,说不清就是它的归属地。压缩**不许**把决策压成无标签的图标——
动词与数值留在场。

**直连宿主变量的白名单。** 只有这几处可以直接写 `--dsw-*`,因为那里要的正是「宿主自己的配方」,
套一层反而会与宿主的模态 / 滚动条不一致:遮罩(`bg-mask` / `mask-blur`)、卡片投影
(`elevation-prominent`)、滚动条(`scrollbar-*-l2`)、悬停底(`interactive-bg-hover` / `-active`)、
侧栏入口自己的常态色与 pressed 色。**别处一律走 `--dtpl-*`。** 形状与配色仍按本文
(宽栏直角、状态色不外借)。

**窄屏(≤640px)。** 浮窗贴底全宽、入场从下方滑入;**直角语言里没有「只圆上角」这条移动端习语**。
其余是判据级的:窗口 tab 排不下就**横向滚动**(不是把最后一个裁掉);网格折行时**分隔线跟着折**;
列头收掉、但 `.dtpl-sr` 列名保留;长且不可预测的值(路由键、路径)可以省略,**摘要与计数保持完整**;
**页头行数不随内容变**(会随数据变宽变窄的那一块单独占一整行,否则它一变宽就把选择器顶到下一行);
**「是不是唯一入口 / 退出」是加宽命中区的唯一理由**,不因为「窄屏」两个字就统一放大。

**无障碍底线。**

- **焦点必须可见、且不被遮挡**;不许在没有替代指示的情况下 `outline:none`。
- **每个动作都要能不用指针完成**;只给 pointer 的交互(拖拽 / 悬停)必须有键盘替代。
- **颜色不单独承载语义**:状态同时要有文字或形状。`title` 只作补充,**信息不能只存在 `title` 里**。
- **动效**:`prefers-reduced-motion` 下必须关掉全部动画,且**关掉之后必须还有反馈**——
  没有哪一处只靠动画传达「正在进行」。
- 功能性图标一律用**内联 SVG**,禁止 emoji。
- 本插件是**桌面 Web 的 DSH 插件**,移动端 App 专章(安全区、haptics、Dynamic Type、底部导航)
  **不适用**。

## 3. 陷阱速查

完整版与验证手法在 [`LESSONS.md`](LESSONS.md);这里只列改界面最容易踩的:

- **CSS 自定义属性在计算值阶段静默失效**:定义在使用者自己的类里,另一个 tab 就取不到,整条声明
  回落(`grid-template-columns:minmax(0,1fr) var(--x)` 会整条作废、变成单列,不是只错一列)。
  哪些度量必须挂根、为什么,写在 `tokens.ts` 文件头。
- **右列宽度是下限,不是定宽**:`.dtpl-row` 的金额列写 `minmax(min-content, 224px)`——224px 是按
  当前这种金额量出来的,位数不受控,写死会让金额在网格轨道里被裁。
- **`--dtpl-accent` 在 DSH 皮肤里等于墨色**——别把它当分类色或强调色(「还没落盘」用的是行侧那道
  **墨色竖条**;写着「未保存」的徽章走 amber,与「价格未知」同一档)。
- **面板用半像素内阴影 + 洗色当边界会糊**;面板不加投影、不为某个 tab 单独提亮、卡内不再套第二只框。
- **重复编码**:把已经印在旁边的数再画一遍形状(占比尺、缓存命中率),或并排两个几乎相等的百分比。
- **静态行不给 hover 洗色**——行不可点,hover 是假的可点承诺。
- **`aria-controls` 指到不存在的 id 比不指更糟**:读数正常、焦点跳空,页面上看不出任何异常。五个 tab
  共用**一个**面板,所以引用五个都指同一个 `id`;按「每格一个面板」去写死就会指空——撤掉引用是对的,
  补一个假 id 不是(`LedgerOverlay.tsx` 的 tab 段记着这条约束)。
- **固定列数字必须等宽 + `tabular-nums`**,否则位宽错开、固定列的可比对性消失。
- 改样式分片时**注释里不能出现反引号**(模板串会被提前闭合,`pnpm typecheck` 当场红)。
- **死类要双向清**:样式表里定义了却没人用的 `dtpl-*`,与 TSX 里挂着却没有规则的 `dtpl-*`,都是残留
  (结构性锚点 `id` / `aria-controls` 与 `dtpl-price-table` / `dtpl-price-col-more` 两个钩子不算)。
- **硬编码色值只许两处**:`var(--宿主变量, #兜底)` 的兜底里,或 `color-mix()` 内的 `#000` / `#fff`;
  其余进 `tokens.ts` 登记。**虚线为 0**(`dashed` / `dotted`),**圆角只许 `0` / `50%` / `var(...)`**。
- 以上大半可判定:`pnpm selfcheck:ui`(纯静态,不构建、不起服务)强制**死类双向 / 硬编码色值 /
  虚线 / 圆角 / `--dsw-*` 白名单 / `prefers-reduced-motion` 与 `:focus-visible` 与窄屏 `@media`
  三段分支的存在性 / 字面量 `aria-controls` 等引用的 id 确实声明**。其余(自定义属性挂根、右列
  `minmax`、hover 洗色、`tabular-nums`、重复编码)仍要人逐条看——它们要的是判断,不是存在性。

## 4. 自检

```bash
pnpm build          # 改了 styles/** 或 .tsx 后必须构建,再刷新页面看真实渲染
pnpm selfcheck:ui   # 同一批改动的静态禁令门,不构建、不起服务;已串在 pnpm test 里
pnpm typecheck      # 改了别的 src/**
```

**渲染验证**:`scripts/preview-overlay.mjs` 预览台(每次 `pnpm build` 后**重启**);
`TOKBOOK_MODE=empty|err` 选空态 / 错态(一个进程一种形状,不是 query flag),`?dark=1` 切深色皮肤,
`?tab=` 与 `?quota=` 直达各面。或浏览器桥接读 `getComputedStyle`(先 `snapshot` 再 `evaluate`,
见 [`LESSONS.md`](LESSONS.md) §6)。

> **截图有个坑**:遮罩带 `backdrop-filter` 时,Chromium 的**整页**截图会把深色卡拍成浅色
> (元素截图与 `getComputedStyle` 都正常)。判断颜色一律以 computed / 元素截图为准,
> 或临时 `overlay.style.backdropFilter='none'` 再整页拍——别据此判定「深色模式坏了」。
