## 1. 不变量（不可协商）

1. **形状跟着风格,颜色跟着宿主。** 直角 + 硬边 + 金属 + 品牌黄是这套语言;底色、文本色、状态色
   一律走 `--dsw-alias-*`(必须同时成立于浅色与深色皮肤)。**不许**把解析出来的具体色值抄进样式,
   **不许**让形态跟着宿主走(圆角按钮、pill 分段器都是被否掉的方向)。
2. **品牌黄是「料」,不是「线」。** 恒定黄只以**实心块 + 墨边**的形态出现(唯一例外是文本选区洗色);
   黄做 1px 线、做文字、做大面积填充一律禁止。**面积也是预算**——新增黄块前先问一句:
   它会不会成为全屏最大的一块饱和面?
3. **全窗口只有一份配方**:一块面板、一种「当前项」、一档数字等宽、一套表面阶梯。任何一面要长得
   不一样,都得先在这里写出理由并登记。
4. **默认状态不染色。** 占比条、额度条、表盘的默认填充是中性墨色。屏幕上出现的每一处色相都意味着
   「这里看一眼」,而唯一恒定的色相是品牌黄。
5. **不引入第二个色相。** 需要「分类」时用**形状**;金额区分靠**字重 + 桶名**,不靠颜色。
   (唯一例外是 hero 卡首那条插画自带的颜色——它是一张图,不承担分类。)
6. **焦点是系统信号,不是这套视觉语言的一部分**:焦点环跟随宿主皮肤,不参与风格化。
7. **不知道就是不知道。** 用量未知 ≠ 0、价格未知 ≠ 免费——界面必须把「未知」说出来,
   不静默按 0 展示,也不把折算值说成支出。
8. **跨 tab 复用的度量挂在插件根上**,不挂在使用者那一节(否则另一个 tab 取不到变量,
   整条声明在计算值阶段静默失效)。
9. **字段还在被编辑时,它不是错误。** 校验与提示只在**提交点**出现(字段失焦 / 离开面板):空值、
   半截串是打字的中间态,打字途中既不写、也不报。报出来的必须同时给出**地点与原因**,并且只能由
   「改好了」或「没有改动了」清掉——不因为继续打字而闪烁(见 D-040)。

## 2. 达标线（可判定）

**色相的三个来源。** 主题色(宿主 `--dsw-alias-*` 经 L2 别名成 `--dtpl-*`)、中性墨色
(`color-mix(fg N%, transparent)`)、状态色(`ok` / `warn` / `err`,**只在真的要看一眼时**)。
黄只出现在当前页标记、峰值标记、工业徽记、文本选区这四类,且都是实心块 + 墨边;
趋势柱、时间轴点、占比尺一律墨色。

**对比度:文本 4.5:1、非文本(边框 / 条 / 图形)3:1、焦点指示 3:1。** 三条硬规则:

- `fg-3` 只承载 ≤10px 短标签与装饰;**任何要读的文本都走 `fg-2`**——包括**未被选中的选项**
  (「当前项」由字重 + 实条 + 洗色说,不靠把没选中的洗淡)。
- `warn` 不许直接做正文(浅色皮肤下只有 2.15:1),文字用 `warn-ink`;`warn` 本身留给边框与底色。
- **新增文本色必须先在浅/深两套皮肤下各量一次**,把实测值写进 `styles/*.ts` 的注释,再进 tokens。

**字号分带。** 9–10px 只给短标签(列头、柱值、芯片、徽章、轴刻度、表盘说明),它装不下一句话;
11–11.5px 是「说明句」的下限;**12px 起才是正文句**。判据是**这句话要不要读**,不是它有多重要。

**直连宿主变量的白名单。** 只有这几处可以直接写 `--dsw-*`,因为那里要的正是「宿主自己的配方」,
套一层反而会与宿主的模态 / 滚动条不一致:遮罩(`bg-mask` / `mask-blur`)、卡片投影
(`elevation-prominent`)、滚动条(`scrollbar-*-l2`)、悬停底(`interactive-bg-hover` / `-active`)、
侧栏入口自己的常态色与 pressed 色。**别处一律走 `--dtpl-*`。** 形状与配色仍按本文
(宽栏直角、状态色不外借)。

**窄屏(≤640px)。** 浮窗贴底全宽、入场从下方滑入;**直角语言里没有「只圆上角」这条移动端习语**。
其余是判据级的:窗口 tab 排不下就**横向滚动**(不是把最后一个裁掉);网格折行时**分隔线跟着折**;
列头收掉、但 `.dtpl-sr` 列名保留;长且不可预测的值(路由键、路径)可以省略,**摘要与计数保持完整**;
**页头行数不随内容变**(会随数据变宽变窄的那一块单独占一整行,否则它一变宽就把选择器顶到下一行);
**「是不是唯一入口 / 退出」是加宽命中区的唯一理由**,不因为「窄屏」两个字就统一放大。

**无障碍底线。**

- **焦点必须可见、且不被遮挡**;不许在没有替代指示的情况下 `outline:none`。
- **每个动作都要能不用指针完成**;只给 pointer 的交互(拖拽 / 悬停)必须有键盘替代。
- **颜色不单独承载语义**:状态同时要有文字或形状。`title` 只作补充,**信息不能只存在 `title` 里**。
- **动效**:`prefers-reduced-motion` 下必须关掉全部动画,且**关掉之后必须还有反馈**——
  没有哪一处只靠动画传达「正在进行」。
- 功能性图标一律用**内联 SVG**,禁止 emoji。
- 本插件是**桌面 Web 的 DSH 插件**,移动端 App 专章(安全区、haptics、Dynamic Type、底部导航)
  **不适用**。

## 3. 陷阱速查

完整版与验证手法在 [`LESSONS.md`](LESSONS.md);这里只列改界面最容易踩的:

- **`--dtpl-accent` 在 DSH 皮肤里等于墨色**——别把它当分类色或强调色(「还没落盘」用的是行侧那道**墨色竖条**;写着「未保存」的徽章走 amber,与「价格未知」同一档)。
- **面板用半像素内阴影 + 洗色当边界会糊**;面板不加投影、不为某个 tab 单独提亮、卡内不再套第二只框。
- **跨 tab 复用的度量挂错地方 → 整条声明静默失效**(同一行高会在两个 tab 里长得完全不同)。
- **重复编码**:把已经印在旁边的数再画一遍形状(占比尺、缓存命中率),或并排两个几乎相等的百分比。
- **静态行不给 hover 洗色**——行不可点,hover 是假的可点承诺。
- **固定列数字必须等宽 + `tabular-nums`**,否则位宽错开、固定列的可比对性消失。
- 改样式分片时**注释里不能出现反引号**(模板串会被提前闭合,`pnpm typecheck` 当场红)。
- **死类要双向清**:样式表里定义了却没人用的 `dtpl-*`,与 TSX 里挂着却没有规则的 `dtpl-*`,都是残留
  (结构性锚点 `id` / `aria-controls` 与 `dtpl-price-table` / `dtpl-price-col-more` 两个钩子不算)。
- **硬编码色值只许两处**:`var(--宿主变量, #兜底)` 的兜底里,或 `color-mix()` 内的 `#000` / `#fff`;
  其余进 `tokens.ts` 登记。**虚线为 0**(`dashed` / `dotted`),**圆角只许 `0` / `50%` / `var(...)`**。
- 以上是可判定的,改完样式逐条自查——`pnpm selfcheck:ui` 已于 2026-09-16 删除,没有脚本替你守。

## 4. 自检

```bash
pnpm build          # 改了 styles/** 或 .tsx 后必须构建,再刷新页面看真实渲染
pnpm typecheck      # 改了别的 src/**
```

**渲染验证**:`scripts/preview-overlay.mjs` 预览台(每次 `pnpm build` 后**重启**);
`TOKBOOK_MODE=empty|err` 选空态 / 错态(一个进程一种形状,不是 query flag),`?dark=1` 切深色皮肤,
`?tab=` 与 `?quota=` 直达各面。或浏览器桥接读 `getComputedStyle`(先 `snapshot` 再 `evaluate`,
见 [`LESSONS.md`](LESSONS.md) §6)。

> **截图有个坑**:遮罩带 `backdrop-filter` 时,Chromium 的**整页**截图会把深色卡拍成浅色
> (元素截图与 `getComputedStyle` 都正常)。判断颜色一律以 computed / 元素截图为准,
> 或临时 `overlay.style.backdropFilter='none'` 再整页拍——别据此判定「深色模式坏了」。
